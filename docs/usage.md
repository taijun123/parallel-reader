# 对读

在 Windows 中并排阅读、标记和对照两份 PDF。文档和批注保存在本机文档库。

## 打开应用

Windows x64 安装包包含桌面应用和本地 Node 运行时。安装后从开始菜单打开“对读 PDF 阅读器”。桌面窗口使用 Microsoft Edge WebView2 Runtime。给其他电脑分发时，使用 ParallelReader-Offline-Setup-x64.exe。这个版本内含微软签名的 Evergreen x64 离线安装程序，会在缺少运行时或版本低于安装包采用的基线时自动安装。轻量版 ParallelReader-Setup-x64.exe 适合已有较新 WebView2 的电脑。目标环境为 Intel/AMD x64 的 Windows 10 22H2 或 Windows 11。安装程序优先识别本机已有的对读文档库，新文档库默认位于当前用户的本地应用数据目录。

使用工程的网页版时，双击 `start.cmd`，浏览器会打开 <http://127.0.0.1:4173>。保持启动窗口打开，关闭该窗口即可停止服务。本机已安装 Node.js，解压便携包后也可以直接启动。其他电脑需要安装 Node.js 24 或更新版本。

发行包自带构建文件、PDF 渲染引擎、字体与字符映射，启动和阅读无需联网。请通过启动脚本打开，直接双击 HTML 无法启动 PDF worker。

## 阅读方式

- 左侧“文档目录”显示本地文件夹和 PDF。点击“新建文件夹”，选择上级目录后输入名称，可创建多级文件夹。
- 点击“导入 PDF”或任意阅读栏的“打开 PDF”，先选择存放文件夹，再从电脑选择文件。目录的导入支持多选；拖入阅读栏的 PDF 也会先询问存放位置。
- 导入会复制文件到 `library/`，保留电脑其他位置的原文件。同名文件会提示冲突，不覆盖已有文档。单个文件最大 500 MB。
- 目录中每份 PDF 的“左栏”和“右栏”可直接打开该文档；“移动”可将 PDF 移到其他文件夹。
- 刷新、关闭网页或重启程序后，文件夹及 PDF 仍会保留，点击目录中的左右栏按钮即可重新打开。也可在资源管理器里向 `library/` 放入 PDF，再点击网页目录的“刷新”。
- 顶部“文档目录”按钮可收起或展开侧栏；阅读模式会自动隐藏目录。窄屏默认收起目录。

- 左右分别打开或拖入一份 PDF，可选中文字并复制。
- 同步滚动和同步缩放是两个独立开关，默认开启。
- 按页位置会对应页面内的位置；按全文进度会对应整个文档的滚动比例。
- 页数或排版不同时，关闭同步滚动，分别找到对应段落，点击“对齐当前位置”，再开启同步。重新开启同步时也会自动保留当前对应关系。
- 点击任意一侧的加减按钮、输入 25% 至 400% 的缩放值，或用 Ctrl + 滚轮缩放。点击“适应宽度”按当前栏宽度缩放；联动时两边使用相同的数值倍率。
- 按住 Alt 可临时独立滚动或缩放。关闭两项同步开关可长期独立控制。
- 点击右上角“阅读模式”可收起顶部栏、两侧文档工具栏和底栏，扩大阅读区。原有同步设置继续生效，滚轮和 Ctrl + 滚轮仍可操作。点击底部悬浮的“退出阅读模式”或按 Esc 恢复工具栏。
- 输入页码可跳页。页面较窄时，阅读区自动改成上下排列。
- 支持输入密码打开加密 PDF。刷新后从目录重新打开，密码需重新输入。

滚动对应根据页位置或阅读进度计算，不会自动识别原文与译文的对应段落。

## 批注与原译关联

选中文字，在浮动工具条选择高亮、下划线或写批注。点击标记可以改色、补笔记或删除。阅读栏的书签按钮用于标记当前页，区域标注按钮可在扫描页或插图上拖出矩形。按 Ctrl+Z 撤销最近一次批注操作。

在左侧切换到“批注”，按当前打开的文档、颜色或类型筛选。点击列表中的普通记录，只移动它所属的阅读栏。要把原文和译文连起来，先编辑其中一条标记，选择关联另一栏，然后在另一栏创建或点选目标标记。再次点击已关联的列表记录，两栏会分别定位到各自的位置。

可把摘录和笔记导为 Markdown，也可把选定文档另存为带批注的 PDF。加密文档支持导出 Markdown。批注使用 PDF 内容标识保存，文件移动后仍可找回。备份前关闭阅读器，然后复制整个文档库，包括库根目录的 `.parallel-reader.sqlite`。

## 开发与验证

```powershell
npm ci
npm run dev
npm run build
npm test
```

测试使用本机 Chrome；无 Chrome 时可在 `playwright.config.js` 中调整浏览器配置。核心代码在 `src/main.js`，滚动坐标换算在 `src/sync.js`。

目录界面在 `src/library.js`，本地文件接口在 `library-api.mjs`。测试使用临时目录，不读写用户的 `library/`。开发服务器同样提供文档目录接口。备份或搬迁程序时，请一起复制 `library/`，不要只复制 `dist/`。发行便携包不包含个人文档。

PDF 渲染采用 Mozilla PDF.js，接口参考 [官方示例](https://mozilla.github.io/pdf.js/examples/)。依赖版本固定在 `package-lock.json`，第三方许可见 `THIRD_PARTY_NOTICES.txt` 及随包资源中的许可文件。
